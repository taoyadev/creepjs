# Contrast Preference

<!-- llms-safe:start -->

## What CreepJS reports

Evaluates preferred-contrast media queries and returns more, less, custom, or no-preference.

## How to interpret it

Change a supported system contrast preference, then compare which label the browser returns.

## Limits

No-preference can reflect default or unsupported behavior. Do not infer a medical condition or a person’s needs from the value. A single signal does not identify a person.

## Test the signal

Keep the live result for comparison, change one relevant setting, then run again in the same tab. Compare the fields before interpreting a changed signature.
