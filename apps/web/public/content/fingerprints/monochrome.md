# Monochrome Display

<!-- llms-safe:start -->

## What CreepJS reports

Evaluates monochrome display media queries and returns the reported monochrome depth.

## How to interpret it

Zero is a valid observation meaning no monochrome capability matched this check; it is not missing data.

## Limits

The result is a media-query observation, not a physical display inspection. Browser support and normalization can affect it. A single signal does not identify a person.

## Test the signal

Keep the live result for comparison, change one relevant setting, then run again in the same tab. Compare the fields before interpreting a changed signature.
