# Screen Information

<!-- llms-safe:start -->

## What CreepJS reports

Reads screen dimensions, available desktop area, color depth, pixel depth, and device pixel ratio.

## How to interpret it

Move this window to another display or change display scaling, then run again. Compare dimensions and pixel ratio separately.

## Limits

Values describe browser-exposed CSS geometry, not necessarily physical panel pixels. Browser privacy settings may standardize the values. A single signal does not identify a person.

## Test the signal

Keep the live result for comparison, change one relevant setting, then run again in the same tab. Compare the fields before interpreting a changed signature.
