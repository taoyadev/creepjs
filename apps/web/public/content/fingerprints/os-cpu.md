# OS CPU

<!-- llms-safe:start -->

## What CreepJS reports

Reads the legacy navigator.oscpu text if it is exposed.

## How to interpret it

Inspect the exact returned text, or treat an unavailable value as unknown. Compare it with other browser hints only as context.

## Limits

The property is not supported everywhere and may be reduced or overridden. It is not verified operating-system information. A single signal does not identify a person.

## Test the signal

Keep the live result for comparison, change one relevant setting, then run again in the same tab. Compare the fields before interpreting a changed signature.
