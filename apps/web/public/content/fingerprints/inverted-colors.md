# Inverted Colors

<!-- llms-safe:start -->

## What CreepJS reports

Checks the inverted-colors media query and returns whether inversion is exposed.

## How to interpret it

Yes and No are valid observations. Change the relevant system display setting and compare the returned flag.

## Limits

The query does not detect every extension, filter, or display transformation. It must not be used to infer a disability. A single signal does not identify a person.

## Test the signal

Keep the live result for comparison, change one relevant setting, then run again in the same tab. Compare the fields before interpreting a changed signature.
