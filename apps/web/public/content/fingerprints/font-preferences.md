# Font Preferences

<!-- llms-safe:start -->

## What CreepJS reports

Reads the computed CSS font-family values for generic serif, sans-serif, and monospace text.

## How to interpret it

Compare the three returned family strings after changing default browser fonts.

## Limits

Computed CSS may keep generic family names instead of revealing the resolved installed font. This is not a complete font inventory. A single signal does not identify a person.

## Test the signal

Keep the live result for comparison, change one relevant setting, then run again in the same tab. Compare the fields before interpreting a changed signature.

- Full checker: https://creepjs.org/checker
