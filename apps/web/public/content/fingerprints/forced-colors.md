# Forced Colors

<!-- llms-safe:start -->

## What CreepJS reports

Evaluates the forced-colors media query and returns an active flag.

## How to interpret it

Compare the active flag after changing a supported system forced-color setting. The value describes browser styling behavior.

## Limits

A false flag does not describe every contrast or accessibility setting. The preference is not an identity or health signal. A single signal does not identify a person.

## Test the signal

Keep the live result for comparison, change one relevant setting, then run again in the same tab. Compare the fields before interpreting a changed signature.
