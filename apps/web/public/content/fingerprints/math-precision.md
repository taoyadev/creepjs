# Math Precision

<!-- llms-safe:start -->

## What CreepJS reports

Evaluates JavaScript math operations and records their results, standard constants, and a signature.

## How to interpret it

Inspect the numeric data in JSON when comparing JavaScript engines. A signature summarizes the observed operation set.

## Limits

The tested operations are a small engine characteristic, not a CPU benchmark. Equal results are common across different browsers. A single signal does not identify a person.

## Test the signal

Keep the live result for comparison, change one relevant setting, then run again in the same tab. Compare the fields before interpreting a changed signature.
