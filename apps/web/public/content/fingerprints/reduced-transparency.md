# Reduced Transparency

<!-- llms-safe:start -->

## What CreepJS reports

Evaluates the prefers-reduced-transparency media query and returns the exposed preference.

## How to interpret it

Change the system transparency setting, if supported, then rerun to compare the browser response.

## Limits

A no-preference result can reflect the default or unsupported query behavior. It is not proof that the preference is unavailable at system level. A single signal does not identify a person.

## Test the signal

Keep the live result for comparison, change one relevant setting, then run again in the same tab. Compare the fields before interpreting a changed signature.
