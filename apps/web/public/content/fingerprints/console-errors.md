# Console Errors

<!-- llms-safe:start -->

## What CreepJS reports

Examines console methods and generated JavaScript error patterns, stack depth, and error prototype properties.

## How to interpret it

Inspect error patterns in JSON when comparing browser engines or instrumentation. These are test-generated errors, not a report of your browsing errors.

## Limits

Developer tools, wrappers, and engine versions affect formatting. A difference does not prove tampering or malicious automation. A single signal does not identify a person.

## Test the signal

Keep the live result for comparison, change one relevant setting, then run again in the same tab. Compare the fields before interpreting a changed signature.
