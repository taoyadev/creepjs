# Open Database

<!-- llms-safe:start -->

## What CreepJS reports

Checks whether the legacy Web SQL openDatabase API is exposed.

## How to interpret it

No is expected in many current browsers and is a complete observation. No result means this check could not return a value.

## Limits

This does not create a database. Legacy API availability is not a recommendation to use it or an overall browser capability score. A single signal does not identify a person.

## Test the signal

Keep the live result for comparison, change one relevant setting, then run again in the same tab. Compare the fields before interpreting a changed signature.
