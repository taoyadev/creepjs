# HDR Support

<!-- llms-safe:start -->

## What CreepJS reports

Tests browser-reported dynamic-range support and returns high or standard.

## How to interpret it

Use the label to compare the browser response across displays or system HDR settings.

## Limits

A high result does not guarantee HDR playback or content quality. It reflects the tested media-query capability. A single signal does not identify a person.

## Test the signal

Keep the live result for comparison, change one relevant setting, then run again in the same tab. Compare the fields before interpreting a changed signature.

- Live signal page: https://creepjs.org/fingerprint/hdr
- Full checker: https://creepjs.org/checker
