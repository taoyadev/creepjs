# CPU Class

<!-- llms-safe:start -->

## What CreepJS reports

Reads the legacy navigator.cpuClass hint if the browser exposes it.

## How to interpret it

No result is normal in browsers that do not implement this legacy property. Do not substitute a guessed CPU class.

## Limits

The hint is browser-reported compatibility data and does not measure processor capability or establish hardware identity. A single signal does not identify a person.

## Test the signal

Keep the live result for comparison, change one relevant setting, then run again in the same tab. Compare the fields before interpreting a changed signature.
