# Language Preferences

<!-- llms-safe:start -->

## What CreepJS reports

Reads browser-reported language preferences and returns the exposed language lists.

## How to interpret it

Compare the ordering and language tags after changing browser language preferences, then rerun in this tab.

## Limits

Language preferences do not identify nationality or a person. Privacy settings can reduce or standardize the list. A single signal does not identify a person.

## Test the signal

Keep the live result for comparison, change one relevant setting, then run again in the same tab. Compare the fields before interpreting a changed signature.

- Full checker: https://creepjs.org/checker
