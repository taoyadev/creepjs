# Browser Plugins

<!-- llms-safe:start -->

## What CreepJS reports

Lists browser-exposed plugin names, descriptions, and associated MIME types.

## How to interpret it

Inspect the entries in JSON. An empty list is a valid observation for browsers that expose no plugins.

## Limits

Modern browsers often return standardized PDF-related entries. This is not an inventory of installed extensions or software. A single signal does not identify a person.

## Test the signal

Keep the live result for comparison, change one relevant setting, then run again in the same tab. Compare the fields before interpreting a changed signature.

- Full checker: https://creepjs.org/checker
