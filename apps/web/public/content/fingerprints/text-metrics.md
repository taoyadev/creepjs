# Text Metrics

<!-- llms-safe:start -->

## What CreepJS reports

Measures text using the browser text-metrics API and returns numeric measurements with a signature.

## How to interpret it

Keep a result before changing font or rendering settings. Compare measurements as well as the summary signature.

## Limits

Fallback fonts and API support affect the result. Text measurements cannot prove a specific physical device. A single signal does not identify a person.

## Test the signal

Keep the live result for comparison, change one relevant setting, then run again in the same tab. Compare the fields before interpreting a changed signature.

- Full checker: https://creepjs.org/checker
